# M2 实施与验证计划

2026-11-03，用户明确“开始 M2”。范围：CRT皮肤及旋钮交互。

## 实现

- Vite + React + TypeScript + shadcn Button，保留root核心编译与M0工程。
- 八九十年代木纹CRT机身、银灰控制面板、4:3弧面屏、扫描线/玻璃反光、机械旋钮与电源开关。
- 可插拔Skin props：消费Controller只读状态、派发电源/频道/音量动作；频道读取M1 Scheduler，音量只存于控制层。
- 内置三路固定预览频道，纯SVG演示信号与无信号；页面明确标注无真实视频，不发远程视频请求。无CRUD/存储/后端。
- 开机/关机/切台过渡，尊重prefers-reduced-motion；旋钮支持拖动、滚轮和键盘；提供直观上一台/下一台按钮。

## 验证

- 核心既有测试回归，增加控制层状态/订阅/电源/音量测试。
- 实际Chrome/Edge浏览器验证电源、频道循环、无信号、旋钮键盘/拖动/滚轮、音量上下限、键盘焦点、减少动态效果和小屏布局。
- 保存结果JSON、控制台/网络证据、开机/关机/无信号/小屏截图；逐项如实判定PASS/FAIL/BLOCKED/NOT RUN。
- 检查lint/typecheck/test/build。M2完成后等待用户验收，不进入M3。
