# M4 技术决策记录

日期：2026-11-04。范围：用户授权的播放器、回归、视觉调整与Docker镜像交付；不启动新阶段、不发布云服务器。

1. **播放器与调度分离**：MediaScreen按调度token创建实例，旧token/关机立即销毁。播放器加载后按当前绝对时间定位，持续有限次校准，不累加播放时间。媒体时长/结束回传核心，提前结束显示无信号。
2. **Chrome/Edge优先hls.js，Safari原生HLS**：Chrome虽报告支持原生HLS，但本轮原生路径出现持续缓冲，初始证据保留在chrome-native-hls-buffering；切换到hls.js后Chrome/Edge各9项闭环通过。Safari单独核验，不用Chromium或Playwright WebKit替代。hls.js缓冲窗口15–30秒，自动选择码率，初始低码率；关机销毁并移除src。
3. **只承诺VOD**：原生路径先读取清单确认ENDLIST，hls.js路径根据LEVEL_LOADED识别live；直播不能满足每日固定时刻定位，显示明确错误。不延长/循环短源伪造1800秒，沿用M0延期。
4. **平台API边界**：YouTube仅官方IFrame API，提供超时、错误及操作恢复提示；本轮网络超时保留BLOCKED。B站仅官方iframe及t参数，不能以iframe加载完成当作播放成功；外部音量禁用并提示用视频内/系统音量，提前结束/状态事件不承诺；恢复前台按当前t重建。受限来源不具备完整电视模式保证。
5. **异常与销毁**：断网恢复重建实例，pagehide释放、pageshow重建，visibilitychange恢复时校准。自动播放受阻显示「点击继续收看」，不能把函数返回当作播放证据。媒体直连源站；不增加业务后端、代理或鉴权绕过。
6. **视觉**：CSS多层阴影、机壳侧面、边框高光和玻璃层构成立体电视，背景采用水泥噪点、泛黄及窗景；未引入Three.js。两种布局屏幕基准640×480，视口不足整体缩放，不滚动页面。配置弹窗改用基于Radix的shadcn/ui组件及统一表单组件，固定高度并内部滚动。属于本轮视觉方案，最终认可仍待用户验收。
7. **交付选择**：按用户要求生成linux/amd64及linux/arm64的Nginx静态镜像和部署说明，用户自行部署。容器只服务静态文件，不持久化用户频道；数据仍在浏览器IndexedDB，跨域名需JSON迁移。没有云部署PASS声明。

初始失败、重测证据及未覆盖项见M4测试报告。M0统计不因本轮新增测试而修改。
