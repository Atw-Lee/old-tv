# M1 实施计划与验收

日期：2026-11-03。授权：用户明确“开始 M1”；M0已验收。仅数据模型、调度器及自动化测试。

## 一致性与边界

PRD/ARCHITECTURE一致：频道通过稳定ID关联节目和排片；固定Asia/Shanghai每日循环；start≤now<end；同频道不重叠；空档/提前结束无信号；关机停止、重开重新计算当前偏移。M0的1800秒真实媒体测试仍延期，M1的1800秒算法测试不能替代它。B站运行期控制仍受限，核心不伪造其结束/状态能力。

本轮建立src/core纯TypeScript模型、运行时数据校验、时钟/排片求值器及调度生命周期；输出播放意图供后续Adapter消费，不宣称真实播放器集成完成。使用注入Clock与Timer验证恢复和节流；无持久化、UI、后端和真实平台新增请求。

## 实施顺序

1. 建立独立根目录核心工具链，保留m0实验工程和原始证据。
2. 定义Channel/Program/Schedule/Settings及配置schema，校验ID/引用/时间范围/重叠/有限数值，提供纯频道导航。
3. 实现Asia/Shanghai日期和毫秒偏移、每日排片与边界求值。
4. 实现电源/频道/配置变化、结束和时长回调、带代号的播放意图、恢复重评估与资源清理。
5. 自动测试边界、跨日、宿主时区差异、旧回调、慢加载、后台/网络恢复、停止与重复订阅清理；形成报告。

## 测试标准

- 运行时拒绝非法配置；相邻排片与跨频道同时播出允许，跨午夜/同频道重叠拒绝。
- 北京09:30相对09:00偏移1800秒，保留毫秒；结束边界进入下一节目或空档；24:00后进入次日。
- 未知时长可开始，实际duration/ended到达后停止且不重播本次排片；次日可重播。
- 关机发出stop且取消定时器，重开、调台、恢复按新时钟求值；旧会话回调不能覆盖新状态。
- 测试使用假时钟/假播放消费者，真实媒体精度/平台策略留在M0证据与后续集成中。
- lint/typecheck/test/build通过。M1验收后再申请M2授权。
