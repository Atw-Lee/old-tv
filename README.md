# 复古电视

一台按北京时间播出的互联网电视。你可以创建频道、添加视频源，为每个频道编排每天循环的节目表。开机或切台时，电视会定位到当前时刻应播的节目。排片空档和素材播完后的剩余时段显示无信号。

## 本地运行

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5190/ ，点击机身上的「调校」，依次添加频道、视频源和排片，点击「保存」后开机。

视频由浏览器直接从来源网站加载。建议使用支持跨域访问和时间定位的点播 HLS 链接。频道和排片保存在当前浏览器的 IndexedDB 中，可通过调校面板导出或导入 JSON 备份。
